# Tic Tac Toe

A simple, offline two-player Tic Tac Toe game built with HTML, CSS, and vanilla JavaScript. Play as X and O on the same board, with no installation or account required.

## Features

- Two-player gameplay on a 3 × 3 board
- Turn, win, and draw status messages
- Winning squares highlighted in red and draw squares in yellow
- Sound effects for moves, wins, and draws, with a mute toggle
- Light and dark themes
- Restart button to start a new game

## Play

1. Download or clone this project.
2. Open `index.html` in a modern web browser.
3. Take turns selecting empty squares. The first player to make a line of three wins; if all squares are filled without a winner, the game is a draw.

No build step, dependencies, or server are required. You can also open the folder in VS Code and use a local preview extension if you prefer.

## Controls

- **Restart** — clears the board and starts a new game with X.
- **Dark Mode** — switches between light and dark themes.
- **Speaker button** — mutes or unmutes game sounds.

Sounds are generated by the browser's Web Audio API. If sound is unavailable in your browser, the game remains playable.

## Project files

- `index.html` — game layout and controls
- `style.css` — board, themes, and styling
- `script.js` — turns, win/draw detection, sound, and controls
