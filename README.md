# Tic-Tac-Toe
This is a intaractive Tic Tac Toe game that we play in paper

## Features
- Offilne Human vs Human Play
- Dark Mode and Light Mode
- Sound effect and animations
- Responsive UI/UX | Modern Interface
- Restart Functionality

## Technology Used
- HTML5
- CSS3
- Java Script

## How to Run
1. Clone this repository
    ```bash
    git clone https://github.com/603codes/Tic-Tac-Toe
    ```
2. Open project
3. Open `index.html` in your browser
